Project Name: SANKET

Problem Statement:
SIH26103 – AI for Infrastructure Project Monitoring

Goal:
Build an AI/ML based early-warning system for infrastructure
projects using PAIMANA project-monitoring data.

Core capabilities:
1. Cost overrun prediction
2. Schedule/time overrun prediction
3. Project risk scoring
4. Explain why a project is risky
5. Early warning alerts
6. Project-level dashboard
7. National/sector-level risk overview
8. What-if simulation
9. Compare ML models with conventional statistical models

Primary ML:
- Logistic/Linear Regression baseline
- Random Forest
- XGBoost
- SHAP

Frontend:
- Streamlit initially

Backend:
- Python

Data:
- PAIMANA/public infrastructure project data
